Built Around Your Minecraft

A launcher experience focused on management, flexibility, performance and control.

Modrinth Integration

Search, filter and one-click install mods, modpacks, resource packs, shaders, datapacks and plugins. The AI Mod Radar scores every project for compatibility and impact.

NeuraX Community

A new built-in community console. Every device gets a stable per-launcher UUID, sends anonymized heartbeats, and shows live online / total counters with a sidebar chip.

Local Server Manager

One-click Paper, Fabric, Vanilla, Forge, NeoForge, Quilt, Spigot, Folia, Purpur and Bukkit servers, with a live stdin console, RAM cap and JVM tuning.

Advanced Configuration

Dark / Light themes, five accent colors, RAM cap, custom JVM args, Discord Rich Presence, lock screen, AFK mode, and full JSON-level launcher control.

A cross-device Community, by design.

NeuraX 4.0.0 ships a full community stack: every launcher auto-generates a stable UUID on first launch, sends an anonymized heartbeat (OS, launcher version, instances, mods, playtime) to a free Supabase backend, and updates a live counter that any other machine can read.

In-launcher Community view

A new sidebar entry in NeuraX shows your UUID, last heartbeat, online count, total users, and recent activity. A small ● N online chip sits in the sidebar and refreshes itself every five minutes.

Standalone nx.py dashboard

Drop nx.py on any Windows machine with Python and PyQt6. It reads the same Supabase backend and shows every device's UUID, OS, instances, mod list and total playtime — no launcher required.

Anonymized telemetry

Only metadata is sent: a random UUID, OS string, launcher version, instance folder names and mod slugs. No Microsoft username, no email, no IP logging. You can toggle the heartbeat off at any time.

Free Supabase backend

Powered by a free Supabase project with row-level security. The publishable key is the only credential, and the SQL schema is a single 20-line CREATE TABLE documented in the README.

Why NeuraX?

Designed for Minecraft players who want more control over how they manage the game.

Open Source Minecraft Launcher

NeuraX is developed as an open-source project with its source available on GitHub. Inspect, fork, and contribute.

Minecraft Version Management

Organize and work with your Minecraft versions from a centralized launcher interface, with loader and Java path per version.

Minecraft Instance Manager

Keep multiple Minecraft environments organized instead of maintaining everything manually. Per-instance RAM, JVM args, and analytics.

Smart Server Discovery

Tokenless radar across mcsrvstat.us, DuckDuckGo, YouTube and Reddit surfaces live community servers, with owner-alias injection for popular creators.

AI Crash Analyzer

Pattern-matches Minecraft log lines for known issues — missing Java, loader mismatch, OpenGL, OutOfMemoryError — and recommends a fix, all local.

Microsoft Auth, Skin & Cape

Full OAuth with keyring-backed silent re-login, custom skin upload, Steve / Alex preview, Mojang cape rendering and legacy 32×32 → 64×64 upscale.

Windows Minecraft Launcher

NeuraX is currently focused on providing a dedicated Windows desktop launcher experience, with PyQt6, QPropertyAnimation and QSS glassmorphism.

Screenshot Gallery

Aggregates every .png under your global and per-instance screenshots folders, with source chips and a click-to-open OS viewer.

Modern Launcher Interface

A clean, modern interface keeps your Minecraft management tools accessible without unnecessary clutter — and the chip system means you can keep your eye on community activity while you play.
